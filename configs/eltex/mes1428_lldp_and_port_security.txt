! ============================================================================
!  ELTEX MES1428 (ПО ISS 10.2.5.2) - проверка/демонстрация LLDP
!  и контроль MAC-адресов на порту
!  IP управления: 10.19.103.30, тестируемый порт: fastethernet 0/11
!  Соответствует разделу 6.2 статьи.
! ============================================================================
!
!  ВАЖНО ПРО СИНТАКСИС
!  --------------------
!  Eltex MES работает под управлением собственной ОС ISS, а НЕ Cisco IOS.
!  Многие команды похожи внешне, но не идентичны, и часть Cisco-команд
!  интерпретатор ISS просто не примет. Проверено на практике: команды
!  "lldp run" и "show ports security" (в Cisco-стиле) отклоняются
!  с ошибкой "Invalid input detected" - переносить конфигурацию
!  "по аналогии" с Cisco IOS нельзя, нужно использовать команды ниже.
!
!  ПЕРЕД НАЧАЛОМ
!  --------------
!  1. Подключитесь к коммутатору через консоль или по SSH/Telnet:
!         telnet 10.19.103.30
!     либо
!         ssh admin@10.19.103.30
!  2. Перейдите в привилегированный режим (если требуется):
!         MES1428>enable
!  3. Уточните нумерацию портов вашего конкретного устройства командой:
!         MES1428#show interfaces status
!     В статье использован порт fastethernet 0/11 - замените на нужный.
!
! ============================================================================
!  ШАГ 1. Проверка ИСХОДНОГО состояния (сделайте это ПЕРЕД любыми
!          изменениями - на MES1428 LLDP по умолчанию ВЫКЛЮЧЕН)
! ============================================================================

MES1428#show lldp
!   Ожидаемый вывод в исходном состоянии:
!     LLDP is disabled
!     LLDP Version: v1
!     Transmit Interval: 30
!     Chassis Id SubType: Mac Address
!     Chassis Id: <MAC-адрес коммутатора>

MES1428#show lldp interface fastethernet 0/11
!   Показывает состояние LLDP конкретно на этом порту.

MES1428#show port-security interface fastethernet 0/11
!   Ожидаемый вывод:
!     MAC learning: enable
!     port security violation type: Restrict
!   Это ОЗНАЧАЕТ, что контроль MAC-адресов уже активен "из коробки" -
!   в отличие от Cisco, здесь НИЧЕГО дополнительно настраивать не нужно
!   для базовой защиты. Restrict = блокировка трафика с чужим MAC БЕЗ
!   перевода порта в состояние down (в отличие от Cisco Secure-shutdown).

! ============================================================================
!  ШАГ 2. Включение LLDP - ТОЛЬКО в учебных/демонстрационных целях,
!          чтобы показать, какая информация "утечёт", если администратор
!          случайно включит протокол на порту доступа
! ============================================================================

MES1428#configure terminal
MES1428(config)#set lldp enable
!   Глобально включает поддержку LLDP на устройстве (сам по себе ещё
!   не заставляет порты передавать/принимать кадры).

MES1428(config)#interface fastethernet 0/11
MES1428(config-if)#lldp transmit
!   Разрешает порту ОТПРАВЛЯТЬ LLDP-кадры.
MES1428(config-if)#lldp receive
!   Разрешает порту ПРИНИМАТЬ LLDP-кадры.
MES1428(config-if)#end

MES1428#copy running-config startup-config
!   Сохраняет конфигурацию в энергонезависимую память (без этой команды
!   изменения пропадут после перезагрузки).

!   Проверка, что порт действительно стал активным:
MES1428#show lldp interface fastethernet 0/11
!   Ожидаемый результат: Tx/Rx state: Tx and Rx Enabled

! ============================================================================
!  ШАГ 3. Возврат к безопасному состоянию (РЕКОМЕНДУЕТСЯ для реальной
!          эксплуатации портов доступа - выполните после демонстрации)
! ============================================================================

MES1428#configure terminal
MES1428(config)#interface fastethernet 0/11
MES1428(config-if)#no lldp transmit
MES1428(config-if)#no lldp receive
MES1428(config-if)#exit
MES1428(config)#no set lldp enable
MES1428(config)#end

MES1428#copy running-config startup-config

! ============================================================================
!  ШАГ 4. Верификация контроля MAC-адресов (Port Security)
! ============================================================================
!  Конфигурация НЕ требуется - режим уже активен по умолчанию.
!  Достаточно убедиться, что настройки не были случайно изменены:

MES1428#show port-security interface fastethernet 0/11
!   Проверьте:
!     MAC learning: enable
!     port security violation type: Restrict
!
!  Если в вашей инсталляции требуется более строгий режим (блокировка
!  порта, а не просто отбрасывание трафика с чужим MAC), уточните
!  в официальной документации Eltex MES14xx актуальный для вашей версии
!  ISS синтаксис изменения violation type - в рамках данного исследования
!  такая перенастройка не выполнялась и не тестировалась.

! ============================================================================
!  ЧАСТЫЕ ОШИБКИ
! ============================================================================
!  - "Invalid input detected" при вводе lldp run / show ports security -
!    это Cisco-команды, на ISS их нет. Используйте команды из этого файла.
!  - Забыли copy running-config startup-config - при перезагрузке
!    коммутатора все изменения откатятся к состоянию "из коробки"
!    (то есть LLDP снова будет выключен - это не ошибка, а особенность
!    ISS: конфигурация не сохраняется автоматически).
!  - Проверяйте порт именно там, где физически включён PC1/тестовый
!    хост - состояние LLDP и Port Security задаётся ПОИНТЕРФЕЙСНО.
