! ============================================================================
!  CISCO IOS — отключение CDP/LLDP и настройка Port-Security
!  Устройства: WS-C2960-24-S, WS-C2960-24TT-L, WS-C3550-24 (статус End-of-Life)
!  Соответствует разделу 6.1 статьи.
! ============================================================================
!
!  ПЕРЕД НАЧАЛОМ
!  --------------
!  1. Подключитесь к коммутатору через консольный порт (кабель RJ-45 -> USB/DB9)
!     или по SSH/Telnet, если управление уже настроено.
!  2. Перейдите в привилегированный режим:
!         Switch> enable
!         Password: <пароль enable, если задан>
!         Switch#
!  3. Определите, какой физический порт подключён к тестируемому/недоверенному
!     сегменту (в статье использовались Fa0/19, Fa0/21 и Fa0/11 на трёх разных
!     коммутаторах). Посмотреть список портов и их статус:
!         Switch# show ip interface brief
!     Ниже FastEthernet0/X — замените X на реальный номер порта вашего
!     устройства (например, interface FastEthernet0/19).
!
! ============================================================================
!  ШАГ 1. Вход в режим глобальной конфигурации, затем в режим конфигурации
!          конкретного интерфейса
! ============================================================================

Switch# configure terminal
Switch(config)# interface FastEthernet0/X
Switch(config-if)#

! ============================================================================
!  ШАГ 2. Отключение протоколов разведки (CDP и LLDP) на этом порту
! ============================================================================
!  no cdp enable       - отключает CDP ТОЛЬКО на этом интерфейсе (глобально
!                        CDP при этом остаётся включённым на других портах,
!                        например на аплинках, где он может быть нужен для
!                        управления сетью).
!  no lldp transmit    - запрещает порту ОТПРАВЛЯТЬ LLDP-кадры.
!  no lldp receive     - запрещает порту ПРИНИМАТЬ LLDP-кадры.
!  Обе команды LLDP нужны одновременно: если оставить только одну,
!  порт продолжит либо рассылать, либо принимать служебную информацию.

 no cdp enable
 no lldp transmit
 no lldp receive

! ============================================================================
!  ШАГ 3. Настройка Port-Security (контроль MAC-адресов на порту)
! ============================================================================
!  switchport mode access                     - порт переводится в режим
!                                                access (обязательно для
!                                                Port-Security - на trunk-
!                                                портах команда работает иначе).
!  switchport port-security                    - включает функцию Port-Security
!                                                на интерфейсе (без этой строки
!                                                остальные команды port-security
!                                                не дадут эффекта).
!  switchport port-security maximum 1          - разрешён ровно 1 MAC-адрес
!                                                одновременно на порту.
!  switchport port-security violation shutdown - при обнаружении второго/чужого
!                                                MAC-адреса порт переводится
!                                                в состояние err-disable
!                                                (в статье - "Secure-shutdown").
!                                                Альтернативы: restrict (не
!                                                отключает порт, но блокирует
!                                                трафик и ведёт счётчик),
!                                                protect (блокирует трафик без
!                                                уведомления/лога).
!  switchport port-security mac-address sticky - коммутатор автоматически
!                                                "запоминает" первый увиденный
!                                                на порту MAC-адрес и добавляет
!                                                его в running-config как
!                                                разрешённый - вручную вбивать
!                                                MAC не требуется.

 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security violation shutdown
 switchport port-security mac-address sticky
 exit

! ============================================================================
!  ШАГ 4. Сохранение конфигурации (иначе изменения пропадут при перезагрузке!)
! ============================================================================

Switch# write memory
! или эквивалентно:
! Switch# copy running-config startup-config

! ============================================================================
!  ШАГ 5. Верификация - проверьте, что защита реально применилась
! ============================================================================

Switch# show cdp interface FastEthernet0/X
!   Ожидаемый результат: интерфейс НЕ отображается в списке с активным CDP,
!   либо явно указано, что CDP на нём выключен.

Switch# show lldp interface FastEthernet0/X
!   Ожидаемый результат: Tx/Rx state: DISABLED (или интерфейс отсутствует
!   в списке активных LLDP-портов).

Switch# show port-security interface FastEthernet0/X
!   Обратите внимание на поля:
!     Port Security             : Enabled
!     Port Status               : Secure-up   (после подмены MAC - Secure-shutdown)
!     Violation Mode            : Shutdown
!     Maximum MAC Addresses     : 1
!     Total MAC Addresses       : 1
!     Sticky MAC Addresses      : 1

! ============================================================================
!  ЕСЛИ ПОРТ УШЁЛ В err-disable ПОСЛЕ ТЕСТА (это ожидаемое поведение!)
! ============================================================================
!  Чтобы вручную поднять порт обратно после теста с подменой MAC:

Switch# configure terminal
Switch(config)# interface FastEthernet0/X
Switch(config-if)# shutdown
Switch(config-if)# no shutdown
Switch(config-if)# exit

! ============================================================================
!  ОТКАТ (если нужно вернуть порт в исходное состояние "из коробки")
! ============================================================================

Switch# configure terminal
Switch(config)# interface FastEthernet0/X
Switch(config-if)# cdp enable
Switch(config-if)# lldp transmit
Switch(config-if)# lldp receive
Switch(config-if)# no switchport port-security
Switch(config-if)# exit
Switch# write memory
